# تجهيز النشر

## البناء والمراجعة

```sh
npm ci
npm run build
npm run preview
```

المعاينة المحلية على `http://127.0.0.1:4173`، وتقدم الصفحات المبنية فعلياً مع 404 صحيح. خادم المعاينة أداة تطوير، وليس خدمة استضافة إنتاجية. لا تحتاج الاستضافة النهائية إلى React SSR server: تستخدم عملية البناء React مرة لإخراج HTML، ثم تُنشر ملفات `dist/` الثابتة فقط.

ينتج البناء ست صفحات لكل لغة تحت `/ar` و`/en`، مع عناوين وأوصاف خاصة وروابط canonical وhreflang وOpen Graph وTwitter وبيانات المؤسسة. المحتوى موجود داخل HTML قبل تشغيل JavaScript. الصفحة الرئيسية `/` تختار اللغة في المتصفح، والصفحات ذات اللغة الصريحة تحتفظ بلغتها. معاملات تصفية المنتجات والحالات لا تُضاف إلى الروابط الأساسية ولا إلى خريطة الموقع.

## إعدادات الاستضافة

| الاستضافة | الإجراء |
| --- | --- |
| Apache / cPanel | ارفع محتويات `dist/` إلى جذر الدومين مع `.htaccess`. يستخدم mod_rewrite للروابط المعروفة، وErrorDocument للمسارات غير الموجودة. |
| Vercel | الإعداد في `vercel.json`: بناء npm، ومجلد `dist`، وخدمة ملفات ثابتة دون افتراض تحويل SPA شامل. |
| Netlify | الإعداد في `netlify.toml`؛ يخرج البناء قواعد `_redirects` للصفحات و404. |
| Nginx | راجع `deploy/nginx.conf.example` ضمن إعداد الخادم الموجود. |

لا تُعد توجيه كل المسارات إلى `index.html`: كل صفحة لها HTML وبيانات مشاركة خاصة، والمسارات غير المعروفة يجب أن تعيد HTTP 404. لا تُعد توجيه طلب صورة مفقودة إلى HTML.

الدومين المرجعي هو `https://www.alsalloummedical.com`. إعداد SSL وتحويل الدومين بدون www إلى الدومين المعتمد يتمان في الاستضافة الفعلية، بعد معرفة بيئتها. لم تتغير إعدادات DNS أو الموقع المنشور.

## فحص قبل الإطلاق

في نافذة ثانية أثناء تشغيل المعاينة، وبعد تجهيز Playwright وفق README:

```sh
npm run verify:launch
```

يفحص الصفحات الـ12 ومحتواها قبل JavaScript، اختلاف الأوصاف، روابط اللغات، صورة المشاركة، خريطة الموقع، 404، سلامة hydration، التصفية، البطء وفشل الصور. لفحوص الواجهة الكاملة على نسخة البناء في PowerShell:

```powershell
$env:TEST_BASE_URL = 'http://127.0.0.1:4173'
npm run verify
```

على الاستضافة الفعلية يُعاد فحص فتح الروابط الداخلية وتحديثها، SSL، وسرعة التحميل من شبكة حقيقية. نجاح الفحوص المحلية لا يمثل قياس أداء ميدانياً.

## نقاط محتوى لم تُغيّر تلقائياً

- البريد `alsalloummedical82@gmaiil.com` كما ورد في الملف الذي أعطاه المستخدم الأولوية. إثبات استقبال الرسائل يحتاج تأكيد صاحب البريد؛ لم تُرسل رسائل اختبار ولم يُستبدل البريد بالتخمين.
- Green مذكورة في المصدر دون رابط يثبت الشركة المقصودة، فبقي اسمها إلى حين وجود دليل لهويتها وشعارها.

هذه الإعدادات تجهز الملفات للنشر، ولا تنشر الموقع أو تربط الدومين تلقائياً.
