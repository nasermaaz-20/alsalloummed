## ما بقي

كود React وAnime.js، إعدادات Vite وTypeScript وGit والاستضافة، `package.json` و`package-lock.json`، سكربتات البناء والمعاينة والفحص، جميع ملفات Markdown الخاصة بالمشروع، بيانات نظام التصميم، الصور الحالية وصور الحالات الست، الخطوط وترخيصها، وملفا الشركة واللوغو الأصليان في `docs/sources/` مع بصماتهما. بقيت الحزم المثبتة لتشغيل المشروع محلياً، وهي مستثناة من Git.

يمكن الاطلاع على أي ملف محذوف أو تنزيله من الـcommit الاحتياطي دون إعادة الملفات القديمة إلى النسخة الحالية. لا توجد تعديلات مقصودة على محتوى الموقع أو واجهته ضمن عملية التنظيف.

## التحقق بعد التنظيف

- نجح `npm run build`، وبقيت بصمتا ملفات JavaScript وCSS كما قبل التنظيف.
- نجح `npm run verify` و`npm run verify:launch` على نسخة البناء، بما يشمل اللغتين والمقاسات والحركة والتواصل واللودينغ و404.
- الصور المستخدمة الـ17 متاحة وتعيد HTTP 200، وبصمتا ملفي PDF الأصليين مطابقتان للمصادر المحفوظة.
- لم تُحذف أي ملفات Markdown خاصة بالمشروع، ولم يتغير كود `src/` أو إعداد التشغيل والبناء. أُزيل 37 ملفاً قديماً أو زائداً من الملفات المتتبعة في Git، إضافة إلى مخرجات التجارب المؤقتة المستثناة أصلاً من Git.
- أُزيلت مخرجات الاختبار وذاكرة البناء المؤقتة بعد إتمام التحقق؛ يعيد البناء والفحص إنشاء ما يحتاجانه، ولا تدخل هذه المخرجات في المستودع.
