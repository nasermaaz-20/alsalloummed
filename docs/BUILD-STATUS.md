# حالة النسخة المحلية

التاريخ: 2026-11-05. النسخة الجديدة مبنية محلياً؛ لم تُنشر على www.alsalloummedical.com.

تم تنظيف ملفات الموقع القديم والأصول المستبدلة والمؤقتات بعد رفع نسخة المصدر كاملة إلى GitHub عند `5ca48e4682e3a04c69b4b20ce161551e4fc0dd83`. الوثائق الأقدم التي تشير إلى أرشيف محلي أو تقارير مراجعات سابقة هي سجل تاريخي؛ موقع الأرشيف الحالي والتفاصيل في [CLEANUP.md](CLEANUP.md). لم يتغير سلوك التطبيق أو تصميمه ضمن التنظيف.

## ما نُفّذ

- تجهيز الإطلاق: 12 صفحة HTML مسبقة للصفحات الست باللغتين، مع وصف مختلف لكل صفحة، canonical وروابط لغات متبادلة وOpen Graph وTwitter وصورة مشاركة 1200×630 وبيانات المؤسسة وsitemap وrobots وصفحة HTTP 404 فعلية في معاينة البناء. لا يحتاج النشر النهائي إلى خادم SSR.
- شاشة بداية محدودة الانتظار، وSkeleton مع shimmer لكل صورة أثناء تحميلها، وظهور ناعم عبر Anime.js وبديل عند الفشل. بداية الحركة الرئيسية تأتي بعد شاشة التحميل. اللوغو المستخدم في الترويسة مضغوط من 606702 إلى 14078 بايت، مع حفظ الأصل.
- إعدادات نشر Apache/cPanel وVercel وNetlify ومثال Nginx، موثقة في `docs/DEPLOYMENT.md`. لم يتم تعديل الدومين أو إعدادات الاستضافة الفعلية.

- React وTypeScript وVite، مع Anime.js الفعلية في الافتتاحية وقائمة الموبايل وعارض الحالات، وتنظيف النطاقات ودعم تخفيف الحركة.
- بعد ملاحظة المستخدم أن الحركة خفيفة أكثر من اللازم: تتابع افتتاحي أوضح للصورة والعنوان والإجراءات، ودخول مخصص للتخصصات والشعارات وبطاقات الشركات والحالات عند الوصول إليها بالتمرير، عبر `src/motion.ts`. المراقبات والحركات تنظف عند التنقل، وتستجيب لتغيير تفضيل تقليل الحركة أثناء فتح الصفحة. لا رسوم مستمرة ولا تمرير مفروض.
- ست صفحات باللغتين العربية والإنكليزية: الرئيسية، عن الشركة، التخصصات والمنتجات، شركات التعاون، الحالات، التواصل.
- اعتماد اللغة من الرابط الصريح أو الاختيار المحفوظ، ثم لغة الجهاز المدعومة، والعربية احتياطياً.
- اللوغو الجديد من PDF، ولوحة مستمدة منه، وخط Alexandria مستضاف محلياً.
- الشركات الموجودة في المصادر، مع إضافة Maxx Orthopedics ورابطها وشعارها الرسمي دون تكرار.
- تحديث صور الواجهة: مشهد تحضير أدوات جراحية مولّد توضيحياً بنسختي WebP، واستبدال الشعارات القديمة لـOrtonom وSpineway وSolid بأصول من مواقعها الرسمية، وتوحيد جميع بطاقات الشركات على تنسيق Maxx. تبقى صور الحالات الأصلية كما هي. المصادر ونص التوليد موثقان في `docs/IMAGE-SOURCES.md` وملفات metadata بجانب الأصول.
- الحالات الست الأصلية: ملخصات وتصفية حسب الاختصاص، ثم تفاصيل وصورة كاملة مع تكبير وتنقل وإغلاق باللمس أو Escape.
- بيانات التواصل من ملف الشركة، وتنزيل الملف الأصلي، وتجهيز رسالة طلب عرض سعر لفتحها في واتساب دون إرسال تلقائي أو تخزين بيانات على خادم.
- صفحة استرداد للمسارات غير الموجودة، وتنقل قابل للمشاركة وروابط التخصص والتصفية.

## التحقق المنفذ

- `npm run verify:launch` اجتاز فحص HTML والبيانات الخام للصفحات الـ12، hydration والتصفية، خريطة الموقع وrobots وصورة المشاركة، 404، القراءة دون JavaScript، تأخير الصور وفشلها، وتعطل ملف JavaScript دون احتجاز الزائر في شاشة التحميل. التفاصيل في `.impeccable/review/launch-verification.json`.

- `npm run build`: فحص TypeScript وبناء Vite نجحا.
- فحوص متصفح محلي headless بسياق مؤقت مستقل عن حسابات المستخدم.
- فحص الصفحات الست باللغتين عند عروض 320 و390 و768 و1024 و1440 بكسل دون تمدد أفقي غير مقصود.
- فحص إعادة التدفق مع تكبير النص 200% على 390px باللغتين.
- فحص فتح القائمة والتنقل وإغلاقها واستعادة التمرير، والتصفية والتكبير والتنقل بين الحالات والإغلاق بـEscape واستعادة التركيز.
- فحص اختيار اللغة وحفظها وأولوية المسار، وتوافر PDF، وتجهيز رابط الاستفسار الصحيح دون إرساله.
- Anime.js تعمل في وضع الحركة الطبيعي، مع React Strict Mode ودون أخطاء JavaScript مرصودة.
- فحص تعزيز الحركة اجتاز مجموعة فحوص الموقع الكاملة؛ تحقق من حركة الافتتاحية، ودخول عناصر خارج الشاشة عند التمرير، وإلغاء التحويلات عند تفعيل تقليل الحركة أثناء الجلسة وإعادتها عند تعطيله، دون أخطاء مرصودة.
- لقطات عربية وإنكليزية للموبايل والكمبيوتر، وحالة تواصل وعارض صور. تقرير الفحص في `.impeccable/review/verification.json`.
- فحص Impeccable الميكانيكي مرة واحدة أعاد قائمة فارغة. هذا ليس شهادة وصول أو أداء ميداني.
- أصول الويب تحمل معلومات المصدر؛ لم تُعدّل الصور أو الملفات المؤرشفة.

## حدود النسخة

تحديث الصور اجتاز البناء وفحصاً موجهاً من 16 مجموعة عبر اللغتين وعروض 320 و390 و768 و900 و1024 و1440، مع إعادة تدفق النص 200% على الموبايل، وصفر أخطاء صفحات أو أصول مرصودة. التقرير واللقطات باسم `image-refresh` و`*-refresh-*` في مجلد المراجعة المحلي. المراجعة المستقلة المذكورة أدناه تخص النسخة السابقة؛ تحديث الصور راجعه المنفّذ بصرياً على الموبايل والكمبيوتر. هذا التحديث محلي ولم يُرفع تلقائياً إلى GitHub.

- الكتالوج يعرض المجالات والتعاونات المدعومة بالمصادر، دون اختراع قائمة موديلات أو أسعار.
- Green معروضة بالاسم؛ لا يوجد أصل شعار معتمد ضمن المرفقات.
- استُخدم البريد كما ورد في المصدر ذي الأولوية `alsalloummedical82@gmaiil.com`؛ قابلية الاستقبال تحتاج حسماً قبل النشر.
- الموقع يحتاج إعداد fallback لمسارات React في الاستضافة النهائية. العنوان التفصيلي للخريطة وساعات العمل وإعدادات الاستضافة لم تُقدم، فلم تختلق.
- لا قياس أداء ميداني، ولا تحقق تشغيلي من توفر المنتجات أو فعالية جهات التواصل. الصور ومحتوى الشركة مستمدان من المصادر المعتمدة من المستخدم.

المراجع المستقل أعاد قرار `ship` على اللقطات الست المقدمة، دون ملاحظات جوهرية. القرار يخص النسخة المحلية والأدلة المعروضة، وليس اعتماداً من المستخدم أو شهادة امتثال شاملة.

المرجع التأسيسي `DESIGN-SYSTEM.md`؛ الحالة البصرية المنفذة موثقة بعد المراجعة في `DESIGN.md`، ومعها `.impeccable/design.json`. تحفظ الأولى التخطيط والأسس، وتصف الثانية القيم المنفذة فعلياً. تنسيق المصدر بـPrettier لم يغير بصمتي ملفات CSS وJavaScript الإنتاجية بعد التقاط الصور.
