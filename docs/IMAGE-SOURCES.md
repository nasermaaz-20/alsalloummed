# مصادر تحديث صور الواجهة

التاريخ: 2026-11-05. طلب المستخدم استبدال صور الواجهة والشعارات فقط، وأبقى صور الأشعة والحالات الأصلية. تبقى الملفات السابقة والمرفقات المؤرشفة محفوظة.

| الأصل | المصدر والاستخدام |
| --- | --- |
| `public/assets/orthopedic-preparation.webp` | مشهد توضيحي مولّد بأداة image_gen المدمجة: تحضير أدوات جراحة العظام، بألوان كحلية وزرقاء وفضية. لا يمثل مقراً أو موظفين أو حالة حقيقية للشركة. النص الكامل للتوليد محفوظ في `orthopedic-preparation.webp.json`. |
| `public/assets/orthopedic-preparation-640.webp` | نسخة 640px من المشهد نفسه للموبايل، دون تغيير محتواه. النسخة الكبيرة 1280px. |
| `public/assets/ortonom-logo.svg` | https://ortonom.com.tr/images/Ortonom-V4.svg — ملف SVG الأصلي المرتبط بترويسة الموقع الرسمي. |
| `public/assets/spineway-logo.svg` | https://spineway.com/us/ — شعار SVG الداكن المضمّن في الترويسة، مستخرج دون إعادة رسم أو تغيير ألوان. |

روابط الشركات الثلاث الأولى المستعملة في البحث موجودة أصلاً في `docs/sources/legacy-site/index.html`؛ أُعيد استخدامها لتحديد الأصول الرسمية، دون إضافة تعاونات جديدة. بصمات الشعارات محفوظة في ملفات JSON المجاورة.

## تتبّع Green

ملف الشركة يذكر Green لمواد التثبيت العظمي، ولا يعطي رابطاً أو اسماً قانونياً كاملاً. أرشيف الموقع يضم روابط Ortonom وSolid وSpineway فقط. البحث بالاسم والتخصص واسم السلوم لم يثبت هوية Green المقصودة. ظهرت شركات ذات أسماء قريبة مثل Greens Surgicals وGreen Apple Surgitech، لكن لم يوجد ما يربطها بالمصدر المعتمد؛ لذلك لم يُنسب شعار إحداها إلى الشركة تعسفاً. يبقى الاسم كما في الملف إلى حين توفر دليل يحددها.
