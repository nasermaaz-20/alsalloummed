# السلوم الطبية — Alsalloum Medical

موقع شركة السلوم الطبية بالعربية والإنكليزية، مبني باستخدام **React + TypeScript + Vite**، مع **Anime.js** للحركة. يشمل التعريف بالشركة، مجالات المنتجات، شركات التعاون، الحالات الجراحية، وطلب عرض سعر عبر واتساب.

رفع الكود إلى GitHub يحفظ المشروع ويتيح تنزيله؛ نشر الموقع على الدومين خطوة مستقلة.

## 1. المتطلبات

- [Node.js](https://nodejs.org/) مع npm. جرى تشغيل المشروع وبناؤه على **Node.js 22.22.3**. يتطلب Vite المستخدم Node.js `20.19+` أو `22.12+`.
- متصفح حديث.
- [Git](https://git-scm.com/downloads) اختياري، لكنه يسهّل تنزيل التحديثات.

بعد تثبيت Node.js، أغلق Terminal وافتح نافذة جديدة، ثم تحقق:

```sh
node --version
npm --version
```

لا يحتاج التشغيل المحلي إلى قاعدة بيانات، أو ملف `.env`، أو مفاتيح API. الصور والخطوط وملف الشركة موجودة ضمن المستودع.

## 2. تنزيل المشروع

### باستخدام Git

افتح Terminal أو PowerShell في المجلد الذي تريد تنزيل المشروع داخله، ونفّذ:

```sh
git clone https://github.com/nasermaaz-20/alsalloummed.git
cd alsalloummed
```

### تنزيل ZIP دون Git

1. افتح [مستودع المشروع](https://github.com/nasermaaz-20/alsalloummed).
2. اضغط **Code → Download ZIP**.
3. فك ضغط الملف بالكامل؛ لا تشغّل المشروع من داخل الملف المضغوط.
4. افتح المجلد الذي يحتوي `package.json` في VS Code، ثم اختر **Terminal → New Terminal**. أو افتح Terminal مباشرة داخل هذا المجلد.

إذا كان المستودع خاصاً، يجب تسجيل الدخول بحساب GitHub لديه صلاحية الوصول.

## 3. تشغيل الموقع محلياً

من داخل مجلد المشروع، ثبّت الحزم أول مرة:

```sh
npm ci
```

ثم شغّل خادم التطوير:

```sh
npm run dev
```

اترك Terminal مفتوحاً، وافتح الرابط في المتصفح:

- العربية: [http://127.0.0.1:5173/ar](http://127.0.0.1:5173/ar)
- الإنكليزية: [http://127.0.0.1:5173/en](http://127.0.0.1:5173/en)

المسار `/` يختار اللغة المحفوظة، ثم لغة جهاز الزائر المدعومة، ثم العربية عند عدم التطابق. تبديل اللغة متاح داخل الموقع.

تظهر تعديلات الكود تلقائياً أثناء تشغيل خادم التطوير. لإيقافه اضغط **Ctrl+C** داخل Terminal. في المرات التالية يكفي `npm run dev`؛ أعد `npm ci` عند تغيير الحزم أو تنزيل تحديث يتضمن ملف القفل.

> لا تفتح `index.html` بالنقر عليه مباشرة؛ الموقع يحتاج خادم Vite بالأمر أعلاه.

## 4. تنزيل التحديثات

إذا نزّلت المشروع باستخدام Git، ومن دون تعديلات محلية متعارضة:

```sh
git pull --ff-only
npm ci
npm run dev
```

أوقف خادم التطوير أولاً إذا كان يعمل. إذا رفض Git التحديث بسبب تعديلات محلية، احتفظ بها أو اعمل commit لها قبل المحاولة مجدداً؛ لا تحذفها عشوائياً.

إذا استخدمت ZIP، نزّل نسخة جديدة وفكها في مجلد جديد، ثم نفّذ خطوات التثبيت والتشغيل. احتفظ بنسختك القديمة إن كنت عدّلت عليها.

## 5. بناء نسخة للاستضافة

```sh
npm run build
npm run preview
```

- ملفات الموقع الناتجة تكون في `dist/`.
- معاينة البناء: [http://127.0.0.1:4173/ar](http://127.0.0.1:4173/ar).
- `npm run preview` لمعاينة البناء محلياً؛ ليس خادم استضافة إنتاجية.
- البناء ينتج 12 صفحة HTML جاهزة للمحتوى والبحث والمشاركة: الصفحات الست بالعربية والإنكليزية، إضافة إلى `404.html` و`sitemap.xml` و`robots.txt`. يتصل React بالصفحات لتفعيل التفاعل، دون خادم Node في الاستضافة النهائية.
- ارفع **محتويات `dist/` كاملة** إلى جذر الدومين، مع المجلدات وملف `.htaccess` المخفي عند استخدام Apache أو cPanel. الصفحات المعروفة لها ملفاتها الفعلية، والمسار غير الموجود يرجع 404؛ لا تستخدم تحويل كل الطلبات إلى الصفحة الرئيسية.
- يتوفر إعداد `vercel.json` لـVercel و`netlify.toml` لـNetlify، ويولد البناء `_redirects`. مثال Nginx في `deploy/nginx.conf.example`، والتفاصيل في `docs/DEPLOYMENT.md`.
- الدومين المعتمد للروابط الأساسية والمشاركة هو `https://www.alsalloummedical.com` داخل `src/seo.ts`. GitHub Pages تحت مسار المستودع يحتاج تغيير إعداد المسار والدومين؛ رفع الكود وحده لا يفعّل الاستضافة.

## 8. فحص الواجهة الآلي — اختياري للتطوير

لا تحتاج هذه الخطوات لمجرد تشغيل الموقع. بعد تثبيت الحزم، افتح PowerShell داخل المشروع ونزّل متصفح الفحص مرة واحدة:

```powershell
$env:PLAYWRIGHT_BROWSERS_PATH = Join-Path $PWD 'tmp/playwright-browsers'
npx playwright install chromium
```

على macOS أو Linux، استخدم بدلاً منه:

```sh
PLAYWRIGHT_BROWSERS_PATH="$PWD/tmp/playwright-browsers" npx playwright install chromium
```

شغّل `npm run dev` في Terminal أول، ثم نفّذ من مجلد المشروع في Terminal ثانٍ:

```sh
npm run verify
```

يمكن تحديد Chrome مثبت مسبقاً عبر `TEST_BROWSER_EXECUTABLE` بدلاً من تنزيل Chromium. إذا اختبرت خادم المعاينة على المنفذ 4173، حدّد `TEST_BASE_URL` إلى `http://127.0.0.1:4173`.

الفحص يشمل اللغات، التنقل، عرض الحالات وتكبيرها، التركيز، روابط واتساب، المقاسات المختلفة وتكبير النص. يعمل بمتصفح مؤقت مستقل ويحفظ التقرير والصور في `.impeccable/review/` المستثناة من Git.

## 9. حلول المشاكل الشائعة

| المشكلة | الحل |
| --- | --- |
| الأمر `node` أو `npm` غير معروف | ثبّت Node.js ثم أعد فتح Terminal أو VS Code |
| PowerShell يمنع تشغيل `npm.ps1` | استخدم `npm.cmd ci` و`npm.cmd run dev`، أو افتح Command Prompt؛ لا يلزم تغيير سياسة النظام |
| يظهر `package.json` غير موجود | انتقل إلى المجلد الذي يحتوي `package.json` قبل تنفيذ الأوامر |
| يظهر خطأ بإصدار Node.js | تحقّق من `node --version` واستخدم إصداراً متوافقاً مع المتطلبات أعلاه |
| المنفذ 5173 أو 4173 مشغول | أوقف النسخة التي تعمل بـCtrl+C، أو استخدم `npm run dev -- --port 5174` وافتح المنفذ الجديد |
| صفحة فارغة عند فتح الملف مباشرة | شغّل `npm run dev` وافتح رابط الخادم، وليس ملف `index.html` |
| فشل تنزيل الحزم أو المتصفح | تحقّق من الإنترنت وإعدادات الشبكة ثم أعد الأمر؛ التنزيل مطلوب أول مرة |
| مسار داخلي معروف يظهر 404 على الاستضافة | تأكد من رفع مجلدات `ar/` و`en/` كاملة من `dist/` ومن تطبيق إعداد الاستضافة المناسب |

## 10. ملاحظات المحتوى والأصول

- بيانات ملف الشركة لها الأولوية على الموقع السابق. لم تُختلق أسعار أو موديلات منتجات أو وكالات حصرية؛ الكتالوج الحالي يعرض المجالات والشركات الواردة في المصادر.
- طلب عرض السعر يفتح واتساب برسالة يراجعها الزائر قبل إرسالها. لا يوجد إرسال تلقائي أو تخزين لبيانات النموذج على خادم.
- البريد المعروض حالياً هو `alsalloummedical82@gmaiil.com` كما ورد في الملف الذي اعتمده صاحب المشروع؛ يلزم التأكد من صلاحيته قبل النشر، ولا يُصحّح تلقائياً.
- شعار السلوم مستخرج من PDF الأصلي، والصور السابقة محفوظة مع مراجعها. صورة الواجهة الجديدة مشهد توضيحي مولّد وليست توثيقاً لمقر الشركة أو لحالة جراحية. شعارات Maxx وOrtonom وSpineway وSolid وGreen مأخوذة من مواقع الشركات الرسمية، ومراجعها بجانب ملفاتها في `public/assets/`. اعتمد المستخدم رابط Green الرسمي `https://greensurgicals.com/index.php`. صور الحالات الجراحية الأصلية محفوظة دون استبدال، وأُلغي تنزيل ملف الشركة من الموقع بناءً على طلبه؛ بقي الأصل ضمن أرشيف المصادر.
- الصور والخطوط المستخدمة موجودة مسبقاً؛ لا توجد خطوة إضافية لتنزيلها قبل التشغيل أو البناء. مصادرها محفوظة بجانب ملفات الأصول وفي وثائق المشروع.
- يحفظ Git الكود و`package-lock.json` والصور والخطوط والمستندات. تُستثنى الحزم والبناء والملفات المؤقتة والملفات البيئية الخاصة؛ يُعاد إنشاء الحزم والبناء بالأوامر أعلاه.
